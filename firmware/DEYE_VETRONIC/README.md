# VEtronic — firmware 4.2-vetronic-32A

Variante avec pilotage d'une passerelle VEtronic WB01 compatible, conservant le profil Deye historique SG02LP1. Elle ne dispose pas du sélecteur de modèles V3.

- [Guide VEtronic](../../docs/GUIDE_VETRONIC.md)
- [Compilation PlatformIO](../../docs/COMPILATION_PLATFORMIO.md), environnement `deye_vetronic`
- [Compilation Arduino IDE](../../docs/COMPILATION_ARDUINO.md), ouvrir `DEYE_VETRONIC.ino` après le BAT de préparation

Le firmware de la passerelle est distinct et n'est pas inclus dans le binaire écran.
